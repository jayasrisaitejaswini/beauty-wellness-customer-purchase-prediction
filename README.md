**Intern:** Battula Jayasri Sai Tejaswini

**Internship:** Data Science with Python Analyst Internship

## Project Overview
This project demonstrates customer purchase prediction and retention analysis using Python and machine learning techniques. It uses the UCI Online Retail dataset as a general-retail proxy to demonstrate methods relevant to the Beauty & Wellness industry.

## Technologies Used
- Python
- Google Colab
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn

## Project Workflow
1. Problem definition and project planning
2. Dataset identification and sourcing
3. Data cleaning and preprocessing
4. Exploratory data analysis and RFM feature engineering
5. Logistic Regression and Random Forest model development
6. Model evaluation and business recommendations

## Model Results
The selected model was Logistic Regression, with:
- Accuracy: 65.21%
- Precision: 69.09%
- Recall: 68.90%
- F1-score: 68.99%
- ROC-AUC: 71.56%

Random Forest was also evaluated and achieved an accuracy of 65.66%.

## Dataset
UCI Online Retail Dataset: https://archive.ics.uci.edu/dataset/352/online+retail

The dataset contains general online-retail transactions, not Beauty & Wellness-specific transactions.

## Project Files
- Google Colab notebook
- Project results ZIP containing evaluation outputs, visualizations, and the saved model

## Limitations
The analysis uses historical general-retail data from 2010–2011. The results should be validated using more recent, industry-specific data before business deployment.
